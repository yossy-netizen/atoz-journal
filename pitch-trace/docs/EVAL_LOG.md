# 評価ログ

`pitchtrace eval --all`（生成 → 合成 → 解析の往復、seed 0、40 音符）の結果を版ごとに記録する。
改良のたびにここへ追記し、数字が悪くなっていないことを確かめる（構想メモ §7、仕様書 §60 の客観評価）。

列の意味: 検出/生成（precision）= 見つけた音符数と余分に切らなかった割合、音高一致 = 音高が正しい音符数、
イントネーション誤差 = 解析と真値の差（セント、基準ピッチ補正後）、ビブラート recall = 0.6 秒以上の音での検出率、
レート誤差 = Hz、深さ比 = 解析 / 真値、ポルタメント recall と時間比、アタック誤差 = セント、基準ピッチ = 推定した A4。

## 残っている課題

- 20 ms 未満のポルタメント（オーボエ、クラシックのサックス）は F0 抽出の分解能で検出できない
- ジャズのサックスはビブラートのレート誤差が大きい（レートの揺らぎが大きく、開始が遅い）
- アタック誤差にまだ +5〜15 セントの正の偏りがある（発音直後の信頼できない区間の扱い）
