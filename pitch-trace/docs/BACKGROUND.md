# 周辺知識 ― PitchTrace を使うために知っておくと役に立つこと

対象読者: PitchTrace の説明に出てくる言葉の意味を知りたい人。
音楽・MIDI・音声解析・統計・ターミナルの最低限を、必要な範囲でまとめます。
読み物として上から読んでも、辞書として引いてもいいように書いています。

## 1. 音の高さと数字

### 1.1 周波数（Hz）

音は空気の振動です。1 秒間に何回振動するかが**周波数**で、単位は Hz（ヘルツ）。
数字が大きいほど高い音。オーケストラが音合わせに使う「ラ」（A4）は 440 Hz が標準です。

### 1.2 半音とオクターブ

ピアノの隣り合う鍵盤が**半音**。12 半音で**オクターブ**（同じ名前の 1 つ上の音）。
オクターブ上がると周波数は 2 倍になります（A4 = 440 Hz、A5 = 880 Hz）。
半音ごとの周波数の比は 2 の 12 乗根 ≒ 1.0595 です。

### 1.3 セント

半音を 100 等分した単位。音の高さの「細かいずれ」を表すのに使います。

| ずれ | 感じ方の目安 |
|---|---|
| 3〜5 セント | ほとんどの人は気づかない |
| 10 セント | 注意して聴くと分かる |
| 20〜30 セント | 「ずれている」と感じる |
| 50 セント | 半音の半分。明らかに違う音 |
| 100 セント | 半音 |

生演奏のビブラートは、上下に 20〜40 セントくらい揺れます。「ずれ」に聞こえないのは、
規則正しく揺れていて、揺れの中心が合っているからです。

セントの計算: 周波数 f と基準 f0 のずれ = 1200 × log2(f / f0)。

### 1.4 MIDI ノート番号

MIDI では音の高さを 0〜127 の番号で表します。60 = 中央のド（C4）、69 = A4（440 Hz）。
番号 1 つ = 半音。PitchTrace の内部では「ノート番号 × 100 + セント」で音の高さを扱います。

### 1.5 平均律と、奏者のイントネーション

ピアノや MIDI の音程は**平均律**（どの半音も同じ比）。でも弦楽器や管楽器の奏者は、
文脈に応じて音を少し高め・低めに取ります（**イントネーション**）。
たとえばクラシックの弦楽器では「導音（次に主音へ行く音）を高めに」「長 3 度を少し高めに」
といった旋律的なイントネーションが一般的です。PitchTrace はこれを「調に対する度数バイアス」
として再現します（`--key` で調を指定、`--no-key-bias` で無効）。

### 1.6 基準ピッチ（A=440 / 442）

オーケストラは A4 を 442 Hz や 443 Hz に合わせることがあります。442 Hz は 440 Hz より
約 8 セント高い。この録音を「常に 8 セント高く弾く奏者」と誤解しないように、
PitchTrace の解析は録音全体から基準ピッチを推定して差し引きます（`--tuning 442` で固定も可）。

## 2. MIDI の基礎

### 2.1 MIDI とは

「どの音を、いつ、どのくらいの強さで、どのくらいの長さ」を書いたデータ。音そのものではなく
指示書です。音源（ソフトウェアの楽器）がこれを読んで音を出します。

主なメッセージ:

| メッセージ | 内容 |
|---|---|
| ノートオン / ノートオフ | 音の始まりと終わり。ノート番号とベロシティ（強さ、0〜127） |
| コントロールチェンジ（CC） | つまみの値。番号で用途が決まっている。CC1 = モジュレーション、CC11 = エクスプレッション（音量表情）、CC7 = ボリューム |
| ピッチベンド | 音の高さをなめらかに動かす。−8192〜+8191 の値 |
| RPN | 「登録済みパラメータ」。RPN 0 でベンドレンジを音源に伝える |
| プログラムチェンジ | 音色の切り替え |
| テンポ、拍子 | ファイルに書かれる演奏情報 |

### 2.2 チャンネル

MIDI には 16 のチャンネルがあり、ピッチベンドや CC は**チャンネルごと**に効きます。
つまり普通の MIDI では、同じチャンネルの音はすべて同じベンドがかかります。
単旋律（1 度に 1 音）なら問題ありませんが、音が重なると困ります。

### 2.3 ピッチベンドとベンドレンジ

ピッチベンドの値は「目一杯で何半音動くか」が決まっていないと意味が確定しません。
それが**ベンドレンジ**。標準は ±2 半音ですが、表情付けには足りないので
PitchTrace は既定で ±12 半音を使います。

**送る側（PitchTrace の `--bend-range`）と受ける側（音源の設定）で同じ値にしてください。**
合っていないと、たとえば 12 で送って音源が 2 だと、動きが 6 分の 1 になり、
ポルタメントが届かず音程がずれて聞こえます。

### 2.4 MPE

MIDI Polyphonic Expression。ノートごとに別のチャンネルを割り当てて、
**音ごとに独立したピッチベンド**をかける仕組み。SWAM や Sample Modeling などの音源、
Logic や Cubase など主要 DAW が対応しています。PitchTrace は `--mode mpe` で出せます。
重なった音（レガートの重なりなど）も正しく扱えます。

### 2.5 MIDI ファイル（.mid）

DAW から書き出せる MIDI のファイル。複数のトラック、テンポチェンジ、拍子が入っています。
PitchTrace は `info` でトラックを確認し、`render --track N` で 1 トラックだけ処理して
残りを保持できます。時間の単位は「tick」（1 拍を 480 や 960 に分けたもの）で、
テンポが変わると 1 tick の長さも変わります。PitchTrace は内部を秒で扱い、
テンポマップで変換します。

## 3. DAW と音源

### 3.1 DAW

Digital Audio Workstation。Logic Pro、Cubase、Studio One、Ableton Live、Pro Tools、Reaper など。
MIDI と音声を並べて曲を作るソフト。

### 3.2 音源の種類とピッチベンドの相性

| 種類 | 例 | ピッチベンドとの相性 |
|---|---|---|
| サンプル音源 | Kontakt 系の多く、Spitfire など | 録音した音を鳴らす。ビブラートやレガートの滑りが**録音に焼き込まれている**ものが多く、外からベンドを足すと二重になる。音源側のビブラートを切るか、CC でビブラート量を制御できるものを選ぶ |
| 物理モデル音源 | SWAM、Sample Modeling | 楽器の仕組みを計算で再現。ピッチベンドや MPE に自然に追従する。**相性が最も良い** |
| シンセ | 各種 | ベンドは効くが生楽器の音ではない |

### 3.3 エクスプレッション（CC11）

多くの生楽器音源は、音量の表情を CC11（またはモジュレーション CC1）で受けます。
PitchTrace は「発音のふくらみ」「フレーズの山へのクレッシェンド」「音末の減衰」を
CC11 に書きます。音源が CC1 で受けるなら `--dyn-cc 1`。

### 3.4 仮想 MIDI ポートと IAC Driver

macOS では、ソフト同士を MIDI ケーブルなしでつなぐ「仮想ポート」が作れます。
PitchTrace の `live` は `PitchTrace In` / `PitchTrace Out` を作ります。
また macOS 標準の **IAC Driver**（Audio MIDI 設定 → MIDI スタジオ → IAC ドライバ →
「装置はオンライン」）でも仮想バスが作れます。

つなぎ方の基本: DAW のメロディトラック → `PitchTrace In` → PitchTrace → `PitchTrace Out` →
DAW の音源トラック。詳しくは [`MAC_SETUP.md`](MAC_SETUP.md)。

## 4. 演奏表現の言葉

| 言葉 | 意味 |
|---|---|
| ビブラート | 音の高さを規則的に揺らす奏法。速さ（レート、Hz）と深さ（セント）で表す。弦楽器は 5〜7 Hz、深さ 20〜40 セント程度が目安。弦とサックスでは中心が目標音より下寄りになりやすい |
| ポルタメント | 前の音から次の音へ、音の高さをなめらかに滑らせること。弦楽器のポジション移動で自然に起こる |
| グリッサンド | ポルタメントに近いが、より意図的・大きな滑り |
| スクープ | 音の出だしを下からしゃくり上げる。ジャズのサックスで顕著 |
| フォール | 音の終わりで高さを落とす。ジャズで多い |
| レガート | 音と音をつなげて弾く（隙間なし、または重なり） |
| デタシェ / タンギング | 音を区切って弾く（弦は弓を返す、管は舌で区切る） |
| イントネーション | 音程の取り方。平均律からの意図的なずれを含む |
| アタック | 音の出だし |
| サステイン | 音を伸ばしている部分 |
| リリース | 音の終わり |
| フレーズ | 音楽的なひとまとまり。息継ぎや休符で区切られる。山（クライマックス）で表情が濃くなる |
| ダイナミクス | 音量の表情（pp、mf、ff や、クレッシェンド） |

## 5. 音声解析の基礎

### 5.1 サンプルレートと WAV

音声をデジタルで扱うときは、1 秒間に何回音の波を測るかを決めます（**サンプルレート**、
44,100 Hz や 48,000 Hz）。WAV はこれを圧縮せずに保存した形式。MP3 は圧縮しているので
細かい解析には向きません。**解析には WAV（16/24/32bit）、モノラル、無伴奏、1 本の楽器**を使ってください。

### 5.2 F0（基本周波数）

楽器の音は基音と倍音でできています。音の高さとして感じるのは基音の周波数で、これを
**F0** と呼びます。録音から F0 を時間ごとに追いかけるのが「ピッチ検出」です。

PitchTrace は **YIN** という古典的で頑丈な方法を内蔵しています。任意で **pYIN**（確率的な改良版、
librosa というライブラリが必要）も使えます。将来は CREPE のようなニューラルネットの検出器も
同じ口から使える設計です。

### 5.3 検出は完璧ではない（信頼度）

弓のノイズ、息の音、発音の瞬間、倍音の強さなどで、F0 検出は間違えます。
代表的なのが**オクターブ誤検出**（本当の音の 2 倍や半分を答える）。
PitchTrace は各時刻に**信頼度**（0〜1）を付けて保存し、前後のつながりから
オクターブ誤検出を補正し、発音直後の信頼できない区間はアタックの推定から外します。
「解析できなかった部分を、できたように見せない」が方針です。

### 5.4 時間の分解能

PitchTrace は 5 ms 刻みで音の高さを追います。ただし F0 検出には約 23 ms の窓を使うので、
それより短い動き（20 ms 未満のポルタメント）は「段差」と区別できません。

### 5.5 ノート分割

連続した F0 の線を「音符」に切り分ける処理。音の高さの段差、無音、音量の落ち込み
（同じ音の連打用）を手がかりにします。ポルタメントの途中で切れることがあるので、
音符の境界とは別に「遷移の始まり・終わり」も記録します。

## 6. 統計の最低限

### 6.1 平均と標準偏差

プロファイルの各パラメータは「平均（mean）」「標準偏差（std）」「下限」「上限」で表します。
標準偏差は「ばらつきの大きさ」。平均 5.8 Hz、標準偏差 0.5 Hz のビブラートなら、
多くの音は 5.3〜6.3 Hz のどこかになります。

### 6.2 分布からサンプルする

PitchTrace は音ごとに、この分布から値を「くじ引き」します。だから同じ MIDI でも
毎回少しずつ違う演奏になります。

### 6.3 乱数の種（seed）

くじ引きの結果を再現するための数。`--seed 3` のように同じ種を指定すると、
同じ結果になります。気に入った結果が出たら種を控えておくと、後で同じものを作れます。
本番の書き出しでは種を固定するのがおすすめです。

### 6.4 recall と precision（評価で出てくる言葉）

`eval` の出力にある言葉。
- recall（再現率）: 本当にある音符のうち、見つけられた割合
- precision（適合率）: 見つけたと言った音符のうち、本当にあった割合
両方 1.0 に近いほど良い。

## 7. ターミナルと Python の最低限

### 7.1 ターミナル

Mac の「ターミナル」アプリで文字のコマンドを打って操作します。
`cd フォルダ名` でフォルダを移動、`ls` で中身を見る。コマンドは 1 行打って Enter。

### 7.2 コマンドの読み方

```
pitchtrace render melody.mid out.mid --profile violin_classical --amount 0.8
   │        │       │          │        │
   │        │       │          │        └ オプション（-- で始まる。順番は自由）
   │        │       │          └ 出力ファイル
   │        │       └ 入力ファイル
   │        └ サブコマンド（何をするか）
   └ プログラム名
```

`pitchtrace render --help` のように `--help` を付けると説明が出ます。

### 7.3 仮想環境（venv）

Python のパッケージをプロジェクトごとに分けて入れる仕組み。
`bash scripts/setup_mac.sh` が `.venv` を作ります。新しいターミナルを開いたら
`source .venv/bin/activate` を打ってから `pitchtrace` を使います。

### 7.4 ファイルの種類

| 拡張子 | 内容 |
|---|---|
| `.mid` | MIDI ファイル |
| `.wav` | 音声ファイル |
| `.json` | 設定や解析結果（文字で書かれたデータ。テキストエディタで開ける） |
| `.igf.json` | PitchTrace の解析結果（IGF） |
| `.png` | 画像（`plot` の出力） |
| `.csv` | 表（`dump` の出力。表計算ソフトで開ける） |
