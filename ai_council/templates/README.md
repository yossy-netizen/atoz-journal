# templates

AI合議制2.0の雛形。事務局タスク（council-clerk-*）と伝令タスクがこの型でファイルを生成する。
配置先（Drive）：`AtoZ_Cowork/Documents/AI会議/合議2.0/06_ペルソナ台帳/_templates/`

| ファイル | 誰が使う |
|---|---|
| 00_軍令状.md | council-clerk-agenda-issue |
| NN_意見書.md | 各伝令・副将Routine |
| 90_採決.md | 事務局が置き、阿藤さんが書く |
| 週次報告.md | council-komei-claude-synthesis |
| _status.json | 事務局が作成、各タスクが更新（inode維持で上書き） |
| 05_人間意見箱_投入テンプレ.md | スタッフ・客席 |
| mai_share_index.html | council-clerk-decision-intake が Dropbox「阿藤舞共有AI合議/index.html」を再生成する雛形 |
| 02_ご意見_投稿テンプレ.md | Dropbox「阿藤舞共有AI合議/02_ご意見/_投稿テンプレ.md」として常設 |
