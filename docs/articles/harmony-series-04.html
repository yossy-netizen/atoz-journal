コードはなぜ「つながって」聞こえるのか ― ボイスリーディングの正体

2026-10-08
ハーモニー音楽理論作曲・編曲メロディー

このシリーズについて

コードには、たくさんの「名前」と「物語」がついています。新しい愛称で呼ばれて、「新種だ」「特別だ」と語られる響きも少なくありません。でも、その多くは、実は昔から音楽の中で使われ続けてきたもの。このシリーズでは、話題のコードや進行を「歴史」と「機能（はたらき）」の両面から、正確に解きほぐしていきます。

理論は、自由な創作を縛る鎖ではなくて。あなたの引き出しを増やすための、頼れる道具です。一つずつ、その扉を一緒に開けていきませんか。

（今回は「ボイスリーディング（声部進行）」——コードとコードを“なめらかにつなぐ”技術のお話です。）

表記について：この記事では、単音をアラビア数字（1, ♭3 など）、コードをローマ数字（I, IIm など）で書き分けます。数字は「キーのドから数えた位置」で、どのキーでも同じように読めます。単音は最初に出てくるときだけ、音名（例：B＝7 の音）を併記します。

はじめに ―「声部進行」は、耳がもう知っている

「ボイスリーディング」「声部進行」——こう聞くと、合唱やクラシックの専門用語のようで、少し身構えてしまいますよね。「コードを押さえられればいいんじゃないの？」と思う方も、きっといるはず。

その感覚も、もっともです。コードは、確かにまず「形」で覚えます。

でも、思い出してみてください。好きな曲のコードが切り替わる瞬間、響きがぶつ切りにならず、すーっと流れていくのを感じたこと…ありませんか。あの「なめらかにつながって聞こえる」感覚——あれを生んでいるのが、ボイスリーディングです。

つまりあなたの耳は、もうとっくにボイスリーディングを感じ取っています。今回やるのは、その感覚に名前と仕組みを与えて、「自分で作れる」側に回ること。難しい規則の暗記ではありません。「音は、できるだけ近いお隣へ歩きたがる」——まずは、この一言だけ持って帰ってください。

正体は「横の線」― コードを“縦”でなく“横”で見る

コードは、ふだん「縦の積み重ね」として見ています。たとえば C なら、下から 1（C）・3（E）・5（G）が積まれた一つのかたまり、という見方です。

ボイスリーディングは、これを90度回転させます。コードが切り替わるとき、一つひとつの音が描く“横の線（メロディの流れ）”に注目していきます。

たとえば、C から Am へ動くとき。それぞれの音がどこへ行くのか、線で追いかけてみます。

  • 1（C） → 1（C）：動かない（共通音）
  • 3（E） → 3（E）：動かない（共通音）
  • 5（G） → 6（A）：となりへ一歩だけ（全音上）

3つの音のうち2つはその場に留まって、1つだけがすっと隣へ動く。これがボイスリーディングの基本の発想です。和音を「ガラッと持ち替える」のではなくて、「最小限の動きで、となりのコードへ乗り換える」。この“横着”こそが、なめらかさの正体です。

やってみよう①
鍵盤で C を押さえて、そのまま G の音（5）だけを A（6）に動かして Am にしてみてください。手は、ほとんど動きません。次に、まったく違う場所で Am を「別の形」で押さえて鳴らしてみると、同じ C→Am でも、つながり方の印象がまるで違うはず。「どの音がどこへ動いたか」で響きの流れが決まる——これを体で感じるのが、第一歩です。

なめらかさを生む、たった3つの原則

ボイスリーディングには難しい規則がたくさんあるように語られがちですが、根っこはとてもシンプル。次の3つだけ意識すれば、響きは見違えてなめらかになります。

  1. 共通音は、動かさない。 二つのコードに共通して含まれる音は、その場にキープ。それだけで二つの和音が“糊づけ”されます。
  2. 動くなら、いちばん近い音へ。 動く必要のある音は、跳ばずに、半音・全音のとなりへ。各声部が小さな“メロディ”を描くように。
  3. 声部どうしを、なるべく交差させない。 上の声部は上で、下の声部は下で動く。線がもつれないほど、耳はなめらかに感じてくれます。

この3つは、バッハのコラールからビートルズのコーラス、ゲーム音楽のストリングスまで、ジャンルを問わず生きています。「なんとなく良い響きでつながっている曲」は、ほぼ例外なく、この原則の上に立っています。

“動きたがる音”がある ― テンデンシートーン

ここで、第2回「ドミナントモーション」の話と、一本につながります。

実は、スケールの中には「じっとしていられない、動きたがる音」があります。これをテンデンシートーン（傾性音）と呼びます。そしてその代表選手こそ——第2回で主役だった三全音を作る、あの2つの音なんです。

Cメジャーキーで考えてみます。動きたがる音は、

  • 7（B＝シの音）：キーの第7音。導音とも呼ばれ、半音上の 1（C）へ上がりたがる。
  • 4（F＝ファの音）：半音下の 3（E）へ下がりたがる。

この 7 と 4——並べてみると、第2回で「ドミナントの緊張のエンジン」とご紹介した三全音そのものです（G7 の中の B と F ＝ 3rd と 7th）。つまり「三全音が解決する」という第2回の話は、声部進行の言葉で言い直すと「7 は 1 へ上がり、4 は 3 へ下がる」という、2本の線の動きだったんですね。

縦で見れば「三全音の解決」、横で見れば「テンデンシートーンの声部進行」。同じ現象を、別の角度から見ているだけ。ハーモニーとメロディが、ここで握手します。

やってみよう②（歌って確かめる）
ここだけ、歌うときの読み方＝ソルフェージュを使うと、体でつかめます。動きたがる音を、声に出してみませんか。
- 導音 7 は「Ti（ティ）」と歌って、半音上の 1「Do（ド）」へ。
- ドミナントの 4 は「Fa（ファ）」と歌って、半音下の 3「Mi（ミ）」へ。

「Ti → Do」「Fa → Mi」と声に出すと、音が行きたがっている方向が、のどと耳ではっきり分かります。ちなみに、半音上げた音は語尾が -i（上に行きたい）、半音下げた音は -e（下に行きたい）の母音になる、という法則も。母音そのものが“進む方向”を含んでいる——だから正しく歌えば、声部進行は理屈の前に、身体に入ってきます。

“止まる音”もある ― 安定音という帰る場所

動きたがる音があるなら、その反対に「どっしり安定して、帰る場所になる音」もあります。

メロディがいちばん落ち着くのは 1（主音）。次に安定するのが 5。その次が 3（または短調的な ♭3）。この「1 → 5 → 3」という安定度の序列は、絶対音感のあるなしに関係なく、ほとんどの人が無意識に共有している感覚です。だから世界中の「みんなが覚えていて、つい口ずさめる」名フレーズは、たいていこの安定音を骨組みにして出来ています。

ボイスリーディングを大きくとらえ直すと、こうなります——動きたがる音（テンデンシートーン）が、安定音へ吸い込まれていく。その吸い込まれる軌跡が、なめらかな“横の線”になる。緊張（動）から安定（静）へ。第2回の「帰りたがる」と同じことが、ここでは一音一音のレベルで起きています。

なぜこれを知ると、得をするのか

ボイスリーディングが手に入ると、いろいろなことが一気に楽になっていきます。

ピアノやギターの伴奏が、見違える。 コードを毎回バラバラの位置で“持ち替える”代わりに、近い音へ最小限で動かすだけで、プロっぽいなめらかな伴奏になります。

コーラスやストリングスのアレンジができる。 各パートを「動きたがる音は行きたい方向へ、安定音はキープ」で書くだけで、声部が自然に歌い出してくれます。

コードの“素顔”が見えるようになる。 どんなに複雑で着飾ったコードでも、「動きたがる音はどれ？ どこへ行きたがってる？」と一音ずつ問えば、正体がほどけます。この“一音ずつ追う耳”は、この先のスケールやテンションの記事すべてで効いてきます。

そして実用上、いちばん効いてくるのが、次回「ガイドトーンボイシング」です。コードの骨格である 3rd と 7th（＝まさにテンデンシートーン）だけを取り出して、その2本の線をなめらかにつなぐ——ボイスリーディングを“最小コスト”で実装する、プロの定番テクニックです。今回の「横の線」の感覚が、そのまま土台になります。

「規則」ではなく「引力」― だから破ってもいい

最後に、いちばん大事なことを。

「共通音はキープ」「近くへ動く」「導音は上がる」——これらは規則（守らねば減点）ではありません。音が自然に“そうしたがる引力”を、言葉にしたにすぎません。

だから、あえて逆らうこともできます。導音をわざと解決させずに浮かせておく。共通音をキープせず、全声部を大胆に跳ばせて、ゴツゴツした力強さを出す。なめらかさが正解の曲もあれば、あえてカクカクさせることが表現になる曲もあります。ロックのパワーコードの潔さも、現代音楽の鋭さも、「なめらかにできると知った上で、あえてそうしない」選択から生まれています。

引力の向きを知っているからこそ、流れに乗ることも、あえて逆らうこともできる。やっぱり、理論は自由の味方です。

まとめ ― 今日からできること

  • ボイスリーディングとは、コードを“縦の積み”ではなく“横の線（各音の流れ）”で見て、なめらかにつなぐ技術。あなたの耳は、もう感じ取っています。
  • 原則は3つだけ。①共通音はキープ ②動くなら最も近い音へ ③声部を交差させない。
  • スケールには動きたがる音（テンデンシートーン）があります。代表は 7 → 1（上がる） と 4 → 3（下がる）。これは第2回の三全音そのもの。縦＝三全音の解決、横＝声部進行で、同じ現象です。
  • 反対に、安定音（1 → 5 → 3 の順で安定）は帰る場所。テンデンシートーンが安定音へ吸い込まれる軌跡が、なめらかな線になります。
  • これらは規則ではなく引力。乗るのも、あえて逆らうのも、表現の自由です。

今日の練習ステップ

  1. C → Am → F → G を、毎回いちばん近い音への移動だけでつないでみる。手の動きが最小になる「楽な道」を探してみる。
  2. 「Ti → Do」「Fa → Mi」を声に出して、動きたがる音の行き先を耳とのどで確かめてみる。
  3. 好きな曲のサビを完コピして、コードが変わる瞬間に「どの音が動いて、どの音が留まったか」を1音ずつ追ってみる。

実際の曲の中で「あ、ここは導音が 1 へ吸い込まれた」「ここは共通音がキープされてる」と見つけられたとき、ボイスリーディングは知識からあなたの耳の力に変わります。完コピ（実際の音に触れること）と理論（仕組みを理解すること）の両輪で、音楽を第一言語にしていきましょう。

理論は、自由の敵ではありません。自由な創作の、いちばん頼れる味方です。
