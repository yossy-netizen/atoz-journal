音楽はなぜ「家に帰りたがる」のか ― ドミナントモーションの正体

2026-10-01
ハーモニー音楽理論作曲・編曲

このシリーズについて

コードには、たくさんの「名前」と「物語」がついています。新しい愛称で呼ばれて、「新種だ」「特別だ」と語られる響きも少なくありません。でも、その多くは、実は昔から音楽の中で使われ続けてきたもの。このシリーズでは、話題のコードや進行を「歴史」と「機能（はたらき）」の両面から、正確に解きほぐしていきます。

理論は、自由な創作を縛る鎖ではなくて。あなたの引き出しを増やすための、頼れる道具です。一つずつ、その扉を一緒に開けていきませんか。

（前回の導入に続く今回は、すべての出発点となる「ドミナントモーション」のお話です。）

はじめに ― 「そんなの知ってるよ」と思った方へ

「ドミナント」「V7 → I」——この言葉を見て、「ああ、あの基本ね」と思った方、きっと多いですよね。コード理論の本なら必ず最初のほうに出てきますし、言葉としてはよく知られています。

その感覚は、まったく正しくて。これは機能和声の中で、いちばん基本的な仕組みのひとつです。

ただ、ひとつだけお伝えしたいことがあります。

この「いちばん基本」こそが、いちばん奥が深い。

ジャズの巨匠も、クラシックの作曲家も、ヒットメーカーも、結局はこの「緊張して、解決する」というたったひとつの動きを、手を変え品を変え使い続けています。このシリーズで後から登場する裏コードも、オルタード・スケールも、さらには「新種」に見える複雑な響きの数々も、突き詰めれば「ドミナントモーションをどう演出するか」のバリエーション。だからこそ、ここを「言葉として知っている」から「身体で感じられる」へ一段深めておくと、この先の景色が一気に変わります。今回は、そのための地図を一緒に広げてみませんか。

まず、結論から ― 音楽は「緊張」と「解決」でできている

コードには、大きく分けて三つの「役割（はたらき）」があります。

  • トニック（T）：安定。落ち着いた、家にいるような状態。
  • サブドミナント（SD）：少し外に出た、ふわっと動きのある状態。
  • ドミナント（D）：強い緊張。「早く家に帰りたい！」という、解決への欲求を生む状態。

このうち、音楽を前へ前へと押し進めるエンジンがドミナントです。ドミナントが生む「帰りたい」という欲求が、トニックへの解決によって満たされる——この一連の流れをドミナントモーションと呼びます。

身近なたとえで言えば、言葉のイントネーションにそっくりです。「これは何ですか↗」と語尾を上げると、答えを待つ宙ぶらりんの状態に。「これはペンです↘」と語尾を下げると、話が着地して落ち着きます。ドミナントは前者の「↗（問いかけ）」、トニックは後者の「↘（着地）」。私たちが言葉の中で無意識にやっていることと、まったく同じことが音楽の中でも起きています。

「帰りたい」を生んでいるのは何か ― 三全音という主役

では、ドミナントの「帰りたい」という強い欲求は、いったいどこから生まれてくるのでしょう。

主役は、三全音（トライトーン）という音程です。

ドミナント7thコード——たとえばCメジャーキーの G7（ソ・シ・レ・ファ）を例にしてみます。このコードの中の 3rd（シ）と 7th（ファ） の間隔が、ちょうど三全音（半音6つ分、全音3つ分）になっています。

この三全音、実にそわそわと落ち着かない響きをしています。あまりに不安定なので、中世ヨーロッパでは「悪魔の音程（diabolus in musica）」と呼ばれて避けられた——そんな逸話まで残っているほどです。

でも、「不安定」は決して欠点ではなくて。不安定だからこそ、安定したところへ動きたがる。 この「動きたがる力」こそが、音楽を前進させるエネルギーの源です。緊張があるから、緩和が気持ちいい。ドミナントモーションの正体は、この三全音が生む緊張だったんですね。

解決の瞬間に、音はどう動くのか

三全音は、不安定なまま放っておかれません。ちゃんと「行き先」を持っています。G7 から C へ解決する瞬間、二つの音が、まるで磁石に引かれるように動きます。

  • シ（3rd・導音） は、半音上の ド へ。
  • ファ（7th） は、半音下の ミ へ。

外側へ広がっていたシとファが、内側のド・ミへすっと収まる。たったこれだけの動きで、G7 の緊張が C の安定へと解決します。とりわけ、キーの第7音である シ は「導音（どうおん）」と呼ばれ、主音（ド）へ強く引きつけられる、解決の主役です。

やってみよう①
鍵盤で G7 を弾いて、続けて C を弾いてみてください。そのとき、「シ → ド」「ファ → ミ」の動きだけを耳で追いかけてみませんか。コード全体ではなく、この二つの線が解決する瞬間に意識を向けると、「解決した！」という気持ちよさの正体が、はっきり掴めてきます。

この「3rd と 7th の動き方」は、実用的なボイシングを組むうえでの土台にもなります。骨格となる 3rd・7th を軸に和音を組み立てる考え方は、別記事「ガイドトーンボイシング」で。複数のコードをまたいで内声を滑らかにつないでいく技術は、「ボイスリーディング」で深掘りしていきます。

「強進行」― 5度下がる動きが、いちばん強い理由

ドミナントモーションには、もう一つの顔があります。ルート（根音）の動きです。

G7 → C のルートは、ソ → ド。これは「完全5度下がる（＝完全4度上がる）」動きです。このルートが完全5度下行する進行を、強進行（ごうしんこう）と呼びます。数あるコードの繋がりの中で、最も強く「解決した感」を生む、王道中の王道です。

なぜ、これがいちばん強いのか。理由は二つあります。一つは、先ほどの三全音の解決（導音と7thの動き）が同時に起きること。もう一つは、ルートが「支配音（ドミナント＝第5音）」から「主音（トニック）」へ、低音でどっしり着地すること。この二つが重なって、最強の解決感が生まれます。

この強進行を数珠つなぎにすると、有名な進行が次々と現れます。

  • D7 → G7 → C（セカンダリードミナントを使った連鎖）
  • Dm7 → G7 → C（ジャズの背骨、ツー・ファイブ・ワン / IIm-V-I）

ルートが完全5度ずつ下りていく流れは、いわゆる「5度圏（サークル・オブ・フィフス）」を反時計回りにたどる動きでもあります。多くの曲が、この「5度で下りて家に帰る」流れを骨格にしています。一度この感覚を掴むと、知らない曲でも「あ、今ドミナントだ。次は解決するな」と、先が読めるようになっていきます。

なお、あるコードを「本来のキーのトニック以外へ向かう一時的なドミナント」として使うのがセカンダリードミナント。これも本質はドミナントモーションで、シリーズの中でたびたび顔を出します。

解決は「義務」ではない ― 引き延ばす・はぐらかす自由

ここまで読むと、「ドミナントは必ずトニックへ解決しなければいけないんだ」と感じるかもしれません。でも、ここがいちばん大切なところで。

解決は、規則ではありません。 ドミナントモーションは「そうしたがる力」であって、「そうしなければならない掟」ではないんですね。むしろ、その力を知った上で、あえて従わないことが、表現の幅を生みます。

たとえば——

  • 解決を引き延ばす：ドミナントを長く鳴らし続けて、聴き手を「まだか、まだか」と焦らす。
  • はぐらかす（偽終止）：G7 のあとを、予想されるトニック（C）ではなく Am へ。これを偽終止（ぎしゅうし）と呼びます。「帰ると見せかけて、隣の部屋へ」という、ほろ苦い意外性が生まれます。
  • 解決先を色づけする：解決そのものは古典的でも、ドミナント側にテンションを足して響きを色っぽくする。

この最後の「色づけ」こそ、ドミナントのいちばん奥深い遊び場です。ドミナント7thに、さまざまなテンション（9th・♯11th・♭13th など）を足していくと、響きは驚くほど色っぽく、複雑になっていきます。それでも、どれだけ着飾っても、その機能は 100% ドミナントのまま——「家に帰りたがっている」という芯は、まったく変わりません。世の中で「エモい」「浮遊感がすごい」と評される響きの多くも、土台にあるのはこのドミナントモーションです。それを知っていれば、見慣れない複雑なコードに出会っても、もう迷子になりません。「ああ、これは着飾ったドミナントだな」と、正体が見抜けるようになります。

仕組みを知らずに「なんとなく鳴らして、うまくいったり、いかなかったり」では、どうしても運任せになってしまいます。解決する道筋を知っているからこそ、あえて寄り道する楽しさが生まれる——「理論は自由の味方」ということの、いちばん分かりやすい例だと思います。

三全音は「2つで1つ」― 次回への扉

最後に、次の記事へつながる種を、ひとつだけ蒔いておきますね。

主役だった三全音には、面白い性質があります。1オクターブをちょうど半分に割るため、上から見ても下から見ても同じ間隔になる、左右対称な音程なんです。

これが何を意味するか。G7 の中の三全音「シ・ファ」は、実はもう一つ別のドミナント7thコードにも、そっくりそのまま含まれています。つまり「同じ三全音を共有する、二つのドミナント」が存在する。この事実が、ジャズの定番テクニックである裏コード（トライトーン・サブスティテューション）の正体につながっていきます。

その話は、第3回「裏コード」でたっぷりと。今回は「三全音は2つで1つ」という感覚だけ、ぜひ覚えて帰ってください。

まとめ ― 今日からできること

  • ドミナントモーションとは、緊張（ドミナント）が安定（トニック）へ解決する、音楽を前へ進めるエンジン。言葉の「問いかけ↗」と「着地↘」と同じはたらきです。
  • 緊張の正体は、ドミナント7thの 3rd と 7th が作る三全音。不安定だからこそ、解決したがります。
  • 解決の瞬間は、導音が半音上へ、7thが半音下へ収束。まずはこの二本の線を、耳で追えるように。
  • ルートが完全5度下がる「強進行」が、最も強い解決感を生みます。IIm-V-I や 5度圏は、この連鎖です。
  • 解決は義務ではありません。引き延ばす・偽終止ではぐらかす・色づけする——仕組みを知った上で外すのが、表現の自由です。

今日の練習ステップ

  1. 好きなキーで V7 → I を弾いて、「シ→ド」「ファ→ミ」の動きだけを聴き取ってみる。
  2. 同じ V7 のあとを、トニックではなく VIm（偽終止） に進めて、響きの違いを味わってみる。
  3. IIm-V-I を 5度圏に沿って、いくつかのキーで弾いてみる。手が「帰り道」を覚えていく感覚を、確かめてみる。

そして何より——実際の曲を完コピして、「あ、ここでドミナントが解決した」「ここは焦らしているな」と、生きた音の中で確かめてみてください。完コピ（実際の音に触れること）と理論（仕組みを理解すること）の両輪で進むことが、音楽を第一言語として無意識に使えるレベルへ近づく、いちばんの近道です。

理論は、自由の敵ではありません。自由な創作の、いちばん頼れる味方です。
