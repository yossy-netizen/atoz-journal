CV Rider 子音と母音を別々にライドする Vocal Rider 系プラグイン（Web Audio 版）

入力を「子音（無声・摩擦・破裂）」と「母音（有声）」に分類し、それぞれ独立したターゲット / レンジ / 速度でレベルを自動ライドします。DAW 用の JUCE 版と同じ DSP コアを AudioWorklet に移植したデモです。

使い方のヒント
  1. モニター → 子音だけを聴く にして、感度 と 分割周波数 を調整し、サ行・タ行・ハ行だけが聞こえる状態を作ります。
  2. モニターを通常に戻し、母音ターゲット をボーカルの狙いレベル（例 −18 dB）に、子音ターゲット をその 4〜8 dB 下に置きます。
  3. 耳障りな歯擦音は 子音トリム で静的に下げ、逆に子音が埋もれる歌い手なら上げます。母音側のライドには影響しません。
  4. 子音の頭が削れる場合は ルックアヘッド を増やします（その分レイテンシが増えます）。

AudioWorklet を使うため、file:// ではなく HTTP で開いてください（例: python3 -m http.server）。
