# CV Rider って何？ — だれでも分かる説明書

> スタッフ・生徒向け。専門用語が出てきたら、そのつど（　）の中で言い換えています。

## 1. ひとことで言うと

**歌の「声の大きさ」を、自動でちょうどよくそろえてくれる道具**です。
しかも、**子音（サ行・タ行・カ行などの「シュッ」「タッ」という音）**と、
**母音（ア・イ・ウ・エ・オの伸びる音）**を**別々に**そろえられます。

## 2. なぜ別々にするの？

歌を録音すると、こんなことがよく起きます。

- 小さく歌ったところが聞こえない → 持ち上げたい
- サビで大きくなりすぎる → 少し下げたい
- 「サ」「シ」の「シュッ」という音（**歯擦音**＝しさつおん）が耳に刺さる → そこだけ下げたい
- 逆に、子音がぼんやりして歌詞が聞き取りにくい → 子音だけはっきりさせたい

ふつうの「自動フェーダー」（**Vocal Rider** という有名なプラグインがあります）は、
声全体をひとまとめに上げ下げします。すると「母音を持ち上げたら、サ行も一緒に大きくなって刺さる」
ということが起きます。

CV Rider は、声を **「今は子音」「今は母音」** と聞き分けて、**それぞれ別のルール**で上げ下げします。

### たとえ話

学校の合唱で、先生が 2 人いると思ってください。

- **母音係の先生**: 「伸ばす声はこのくらいの大きさで」と、ゆっくり手で合図する
- **子音係の先生**: 「シュッ、タッという音はこのくらいで」と、素早く合図する

CV Rider の中には、この 2 人の先生（＝**ライダー**）がいて、
声を聞きながら「今は母音係の番」「今は子音係の番」と交代しています。

## 3. 画面の見方

画面は大きく 3 つに分かれています。

1. **上の帯（検出）**
   青←→オレンジのバーが、「今、母音っぽい（青）か、子音っぽい（オレンジ）か」を示します。
   その下の 4 つの数字は「入力の大きさ」「母音係が今どれだけ上げ下げしているか」「子音係が…」「合計」。
   さらに下の波形のような画面（**スコープ**）は、その動きの履歴です。
2. **真ん中（母音ライダー / 子音ライダー）**
   それぞれ 5 つのツマミ。意味は下の表のとおり。**青が母音、オレンジが子音**です。
3. **下（検出器 / 出力）**
   「子音と母音をどう聞き分けるか」の調整と、最後の音量。

### ツマミの意味（母音・子音で共通）

| ツマミ | 意味 | たとえ |
|---|---|---|
| **Target（ターゲット）** | 「この大きさにそろえてね」という目標 | 先生が決める「基準の声の大きさ」 |
| **Range（レンジ）** | 上げ下げしてよい最大の量 | 「上下 6 dB まではいじっていいよ」という許可の範囲 |
| **Attack（アタック）** | 大きすぎるとき、下げる速さ | 手を下げる速さ |
| **Release（リリース）** | 小さすぎるとき、上げる速さ | 手を上げる速さ |
| **Trim（トリム）** | 目標とは別に、常にかける固定の上げ下げ | 「子音は全部ちょっと小さめで」という一律ルール |

**dB（デシベル）**は音の大きさの単位です。目安として、**6 dB 上げると「約 2 倍の大きさに感じる」くらい**、
**3 dB は「少し大きくなったな」**くらいです。

### 検出器のツマミ

| ツマミ | 意味 |
|---|---|
| **Sensitivity（感度）** | 右に回すほど「子音だ」と判定されやすくなる。歯擦音を取りこぼすなら右、息やかすれ声まで子音扱いされるなら左 |
| **Split（分割周波数）** | 「この高さより上の音が多ければ子音」という境目。ふつうは 4000 Hz のままで OK |
| **Idle（アイドル閾値）** | これより小さい音（無音・部屋のノイズ）は何もしない。ノイズを持ち上げないための安全装置 |
| **Lookahead（先読み）** | ほんの少し（数ミリ秒）先の音を見てから動く。子音の頭が削れるときに増やす |

### 出力

| 項目 | 意味 |
|---|---|
| **Output** | 最後の音量 |
| **Monitor** | **Consonants** にすると「子音だと判定した部分だけ」が聞こえる。**Vowels** は母音だけ。判定が合っているか耳で確かめる用 |
| **Bypass** | 効果をオフにして、かける前と聞き比べる |
| **Preset** | よく使う設定のセット（次の章） |

## 4. 使い方 3 ステップ

1. **プリセットを選ぶ**
   迷ったら **Lead Vocal**。刺さる「サ行」だけ何とかしたいなら **De-ess Only**。
2. **判定が合っているか確かめる**
   Monitor を **Consonants** にして再生。「サ・シ・タ・ハ」の音だけが聞こえれば OK。
   母音まで聞こえてしまう → Sensitivity を左へ。サ行が聞こえない → 右へ。
   確かめたら Monitor を **Off** に戻す（戻し忘れ注意！）。
3. **母音と子音の目標を決める**
   - 母音の Target: 歌の「ちょうどいい大きさ」（目安 −18 dB）
   - 子音の Target: 母音より 4〜8 dB 小さめ（目安 −24 dB）
   - サ行がまだ刺さる → 子音の Trim を −2〜−4 dB
   - 歌詞が聞き取りにくい → 子音の Trim を +2 dB

## 5. プリセットの使い分け

| プリセット | こんなとき |
|---|---|
| **Default** | 出発点。標準的な設定 |
| **Lead Vocal** | ふつうのポップス / ロックのメインボーカル |
| **Gentle** | もともと上手に歌えているテイクを、軽く整えるだけ |
| **De-ess Only** | 母音はさわらず、サ行の刺さりだけを抑えたい（ディエッサー代わり） |
| **Clarity** | 子音がぼやけて歌詞が聞き取りにくい歌い手、音数の多いオケ |
| **Breathy** | ウィスパー系・息混じりの声。息を子音とまちがえないように感度を下げてある |
| **Narration** | ナレーション・朗読。母音を広めにそろえ、子音はしっかり下に |

## 6. 困ったとき

| 症状 | 原因と対処 |
|---|---|
| 音が「ブレス（息）」のたびに持ち上がる | 息を子音と判定している。Sensitivity を左へ、または Breathy プリセット |
| サ行がまだ刺さる | 子音の Trim を下げる。それでもダメなら Sensitivity を右へ（判定を増やす） |
| 子音の頭が「欠けた」ように聞こえる | Lookahead を増やす（5〜8 ms）。DAW が自動で遅れを補正します |
| 全体に「呼吸するみたいに」ふわふわする | 母音の Range を小さく、Attack / Release を遅く（Gentle プリセットの値が参考） |
| プラグインが DAW に出てこない（Mac） | `install-mac.sh` を実行したか、DAW を再起動したか確認。Logic は「プラグインマネージャー」で再スキャン |
| 「開発元を確認できない」と出る（Mac） | ダウンロードしたファイルの隔離マークが原因。`install-mac.sh` が外してくれます |

## 7. 気をつけること

- **Monitor を戻し忘れない**。Consonants のままだと母音が消えたままになります。
- CV Rider は「音量をそろえる」道具で、EQ（音色を変える）ではありません。刺さる音色そのものを丸くしたいときは EQ やディエッサーと併用します。
- かけすぎると不自然になります。**Range は小さめから**始めるのがコツです。
