# CV Rider を使うための周辺知識

> 「なぜそう動くのか」が分かると、ツマミの意味が腑に落ちます。順番に読めるように並べました。

## 1. 音の大きさと dB

- **dB（デシベル）**は「基準に対して何倍か」を対数で表した単位です。音量では **+6 dB ≒ 振幅 2 倍**、**+20 dB = 10 倍**、**+3 dB ≒ 電力 2 倍（「少し大きい」）**。
- **dBFS**（デシベル・フルスケール）はデジタル音声の基準で、**0 dBFS が最大**。ボーカルトラックの平均レベルは −24〜−12 dBFS あたりが普通です。CV Rider の Target はこの dBFS で指定します。
- **RMS（実効値）**は「ある時間幅での平均的な大きさ」。瞬間の最大（ピーク）ではなく、耳が感じる音量に近い量です。CV Rider は母音を **40 ms** の RMS、子音を **5 ms** の RMS で測ります。子音は短いので、速く測る必要があるからです。

## 2. 声の中の「子音」と「母音」

- **母音**（ア・イ・ウ・エ・オ）は声帯が振動する**有声音**。基本周波数（男声 100〜150 Hz、女声 200〜300 Hz）とその倍音でできていて、エネルギーの大半は **4 kHz より下**にあります。母音の音色は**フォルマント**（声道の共鳴、F1・F2・F3…）で決まります。
- **子音**の多くは**無声音**で、声帯を使わず、口の中の狭いところを空気が通るときの**雑音**です。
  - **歯擦音**（サ行・シャ行・ザ行の「s」「sh」）: エネルギーが **4〜10 kHz** に集中。耳に刺さりやすい。
  - **摩擦音**（「f」「h」）: 広い帯域の弱い雑音。
  - **破裂音**（「t」「k」「p」）: ごく短い（10〜20 ms）「破裂」の雑音。
- 「ザ」「ジ」「ヴ」のような**有声の子音**は、声帯の振動と雑音が同時に出ます。CV Rider は雑音成分の割合で判定するので、これらは「半分子音」のように扱われます（クロスフェード）。

## 3. CV Rider はどうやって聞き分けているか

1. 入力を **4 kHz（Split）より上だけ**取り出した信号を作る（ハイパスフィルタ）。
2. 「上だけの音のエネルギー ÷ 全体のエネルギー」を常に計算する（**帯域比**）。
   - 母音: 上の成分は少ないので −20〜−30 dB
   - サ行: ほとんどが上の成分なので 0 dB 近く
3. その比が **しきい値（既定 −9 dB、Sensitivity で動く）** を中心に ±4 dB のなだらかな境界で 0（母音）〜1（子音）の**子音確率 c** になる。
4. 破裂音は短すぎて帯域比が上がりきらないことがあるので、**上の帯域の急な立ち上がり（トランジェント）**も見て補う。
5. 無音や部屋のノイズ（**Idle** より小さい音）は子音と数えない。

## 4. 「ライダー」と「コンプレッサー」の違い

- **コンプレッサー**は「しきい値を超えた分を圧縮する」道具。音が大きいときだけ働き、**波形のピークにも反応**するため音色が変わることがあります。
- **ライダー（自動フェーダー）**は「目標のレベルに向かってフェーダーをゆっくり動かす」道具。人がフェーダーを手で書くのと同じ結果を自動で作ります。音色はほぼ変わらず、**上げる**こともできます。
- CV Rider は後者。ただし子音用のライダーは **1〜2 ms** の速さで動くので、歯擦音に対しては**ディエッサー**（サ行だけ下げるコンプレッサー）に近い働きもします。

### ツマミの中身

- **Target**: 目標レベル。測ったレベルとの差がそのまま「動かしたいゲイン」。
- **Range**: 動かしてよい上限（±）。Range = 0 にするとそのライダーは動きません（Trim だけ効く）。
- **Attack / Release**: ゲインが下がる / 上がる速さ（時定数）。母音は数十〜数百 ms、子音は数 ms が普通。
- **Trim**: 目標とは無関係に常にかける固定ゲイン。「子音は一律 −3 dB」のような使い方。
- **母音ゲインのホールド**: 子音が鳴っている間、母音係は動きも測定も止めます。大きな「s」で母音のレベルを見誤らないためです。

## 5. ルックアヘッドとレイテンシ

- **ルックアヘッド（先読み）**: 音を数 ms 遅らせて出力し、その間に検出器が「次に子音が来る」と知ってゲインを動かします。これで子音の頭が削れません。
- 遅らせた分が **レイテンシ（遅れ）** になります。CV Rider は遅れの量を DAW に報告するので、DAW の **自動遅延補正（PDC）** が他のトラックとタイミングを合わせてくれます。
- リアルタイムで歌いながらモニターする用途では、遅れが気になるなら Lookahead を 0 にします。

## 6. サンプルレートとバウンス

- **サンプルレート**（44.1 / 48 / 96 kHz）は 1 秒間に音を何回測るか。CV Rider の時間系のパラメータ（ms）はどのレートでも同じ動きになるよう設計・テストしています。
- **バウンス（オフライン書き出し）**でも、リアルタイム再生と同じ結果になります（起動直後のレベルずれを修正済み）。

## 7. プラグインの形式（Mac）

- **AU（Audio Units）**: Apple の形式。**Logic Pro / GarageBand** はこれだけ。`~/Library/Audio/Plug-Ins/Components/` に入れる。`auval` は Apple の検証ツールで、合格しないと Logic に出てきません。
- **VST3**: Steinberg の形式。**Cubase / Studio One / Ableton Live / Reaper** など。`~/Library/Audio/Plug-Ins/VST3/` に入れる。
- **Standalone**: DAW なしで単体で動くアプリ。マイクを直接つないで試すのに便利。
- **ユニバーサルバイナリ**: Apple Silicon（M1〜M4）と Intel の両方で動く 1 つのファイル。Rosetta 上の DAW でも動きます。
- **署名と隔離**: インターネットからダウンロードしたアプリは macOS が「隔離」マークを付け、開発元が確認できないと開けません。`install-mac.sh` は隔離を外して「アドホック署名」（自分の Mac 用の簡易署名）を付けます。配布用の正式署名（Developer ID + 公証）は行っていません。

## 8. 関連する道具との併用

- **EQ**: 音色を変える。刺さる帯域そのものを削りたいときは EQ を、刺さる「瞬間」だけ下げたいときは CV Rider の子音側を使う。
- **ディエッサー**: 歯擦音専用のコンプレッサー。CV Rider の De-ess Only プリセットで代替できることが多いが、細かい帯域指定が要るなら併用。
- **コンプレッサー**: CV Rider の**後**に軽く。先にレベルがそろっていると、コンプは音色づくりに専念できる。
- おすすめの順番: **ピッチ補正 → CV Rider → EQ → コンプ → リバーブ**。
